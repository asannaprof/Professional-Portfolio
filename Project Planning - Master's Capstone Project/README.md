# Project Planning - Master's Capstone

The materials in this folder document the development of my master's capstone project at McDaniel College. The project required me to transform a complex, open-ended assignment into a structured research and development initiative.

## Contents

This folder includes:

- **Project Overview** - Initial project scope and objectives
- **Planning Documents** - Timelines, milestones, and resource allocation
- **Research Materials** - Background research and literature review
- **Development Stages** - Progress documentation through each phase
- **Deliverables** - Final project outcomes and artifacts

## Project Goals

The capstone project aimed to:

- Apply advanced academic skills to a comprehensive project
- Demonstrate mastery of subject matter and research methodologies
- Produce original, meaningful work
- Document the entire development process

## How to Navigate

1. Review the project overview for context
2. Follow the planning timeline to understand project progression
3. Examine research and development materials in order
4. Review final deliverables for project outcomes
